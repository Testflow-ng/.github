# Testflow

Testflow is a computer-based testing platform built to make examinations simple, reliable, and accessible for students in Obafemi Awolowo University.

## What we build

We create tools for the full assessment journey:

- Secure student and administrator access
- Flexible question banks and examination management
- Timed CBT examinations with answer saving and navigation
- Results, performance insights, and progress tracking
- Responsive web and native mobile experiences

## Our projects

| Project | Description | Technology |
| --- | --- | --- |
| [Testflow Frontend](https://github.com/Testflow-ng/testflow-frontend) | Student and administrator web application | React, Vite, Tailwind CSS |
| [Testflow Backend](https://github.com/Testflow-ng/testflow-backend) | API and platform services | Node.js, Express, MongoDB |
| [Testflow Mobile](https://github.com/Testflow-ng/testflow-mobile) | Student mobile application | Flutter |

## Getting started

Each project has its own setup guide. For a complete local environment, start the backend, then configure the frontend or mobile app to use its API URL.
